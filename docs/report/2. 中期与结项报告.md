## 一、项目概述  【中期必填】

### 1. 项目背景
随着高校规模的不断扩大，学生宿舍管理工作日益复杂。传统的人工管理方式存在效率低下、信息不透明、数据易丢失等问题。为了提高宿舍管理的效率和服务质量，开发一套现代化的学生宿舍信息管理系统势在必行。
本系统旨在实现宿舍管理的信息化、规范化和智能化，为学生、宿管员和管理员提供便捷的操作平台，提升校园生活服务水平。

### 2. 系统目标
- 实现学生、宿舍、设备等信息电子化管理
- 规范入住、退宿、报修、访客登记等业务流程
- 为学生提供在线报修、电费查询、离归登记等自助服务
- 为宿管员与管理员提供高效管理工具

### 3. 开发环境
（列出主要开发工具、运行环境和数据库）
- 前端：Vue 3.3.4、Element Plus 2.4.2、Pinia 2.1.7、Vite 4.5.0
- 后端：Spring Boot 3.1.5、MyBatis 3.0.2、Java 17
- 数据库：MySQL 8.0
- 身份认证：JWT 4.4.0
- 运行环境：Windows 11、Chrome 120+、JDK 17、Node.js 18.x

## 二、需求分析  【中期必填】

### 1. 功能需求
系统分为学生、宿管员、管理员三类角色，核心功能如下：
- 学生：个人信息管理、设备报修、电费查询、卫生检查查看、离归登记、夫妻房申请、访客登记
- 宿管员：工作台、报修处理、离归管理、卫生管理、电费管理、房间管理
- 管理员：数据统计、学生管理、宿管员管理、楼栋管理、房间管理、入住管理、访客审批
- 公共模块：用户登录注册、权限控制、数据增删改查
（概述系统主要功能及业务流程）

### 2. 非功能需求

- 性能：页面响应时间 < 2 秒，支持 100 + 并发用户
- 安全：JWT 认证、密码加密、防 SQL 注入
- 可用性：界面友好、操作简便、响应式设计
- 兼容性：支持 Chrome、Firefox、Edge、Safari 主流浏览器

> 中期要求：功能清单、主要业务流程、基本非功能需求应明确。

## 三、系统设计  【中期必填】

### 1. 系统架构
采用前后端分离 B/S 架构，分为三层：
- 表现层：Vue 3 + Element Plus + Vue Router + Pinia + Axios
- 业务层：Spring Boot + MyBatis + JWT
- 数据层：MySQL 8.0
- ![系统架构图](./assets/系统架构图.png)
（说明系统总体架构并附架构图）

### 2. 模块设计
- 用户认证模块：登录、注册、密码修改、权限控制
- 学生管理模块：信息增删改查、搜索、入住状态管理
- 宿舍管理模块：楼栋 / 房间管理、入住 / 调宿 / 退宿办理
- 报修管理模块：报修提交、处理、状态跟踪
- 访客 / 电费 / 卫生 / 离归 / 夫妻房模块：对应业务流程管理
（说明主要模块及其职责关系）

### 3. 数据库设计
核心实体：用户、学生、楼栋、房间、宿管员、报修、访客、入住记录等，存在一对多、多对一关联关系。

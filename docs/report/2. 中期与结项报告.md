## 一、项目概述  【中期必填】

### 1. 项目背景
随着高校规模的不断扩大，学生宿舍管理工作日益复杂。传统的人工管理方式存在效率低下、信息不透明、数据易丢失等问题。为了提高宿舍管理的效率和服务质量，开发一套现代化的学生宿舍信息管理系统势在必行。
本系统旨在实现宿舍管理的信息化、规范化和智能化，为学生、宿管员和管理员提供便捷的操作平台，提升校园生活服务水平。

### 2. 系统目标
- 实现学生、宿舍、设备等信息电子化管理
- 规范入住、退宿、报修、访客登记等业务流程
- 为学生提供在线报修、电费查询、离归登记等自助服务
- 为宿管员与管理员提供高效管理工具

### 3. 开发环境
（列出主要开发工具、运行环境和数据库）
- 前端：Vue 3.3.4、Element Plus 2.4.2、Pinia 2.1.7、Vite 4.5.0
- 后端：Spring Boot 3.1.5、MyBatis 3.0.2、Java 17
- 数据库：MySQL 8.0
- 身份认证：JWT 4.4.0
- 运行环境：Windows 11、Chrome 120+、JDK 17、Node.js 18.x

## 二、需求分析  【中期必填】

### 1. 功能需求
系统分为学生、宿管员两类角色，核心功能如下：
- 学生：个人信息管理、设备报修、电费查询、卫生检查查看、离归登记、夫妻房申请、访客登记
- 宿管员：工作台、报修处理、房间管理，数据统计、学生管理、楼栋管理、房间管理、入住管理、访客审批
- 公共模块：用户登录注册、权限控制、数据增删改查

### 2. 非功能需求

- 性能：页面响应时间 < 2 秒，支持 100 + 并发用户
- 安全：JWT 认证、密码加密、防 SQL 注入
- 可用性：界面友好、操作简便、响应式设计
- 兼容性：支持 Chrome、Firefox、Edge、Safari 主流浏览器

##### 3.1.2 JWT认证实现
- 后端使用JWT进行身份认证
  
``` java
public class JwtUtil {
    @Value("${jwt.secret}")
    private String secret;
    @Value("${jwt.expiration}")
    private Long expiration;

    public String generateToken(Long userId, String username, String role) {
        return JWT.create().withClaim("userId", userId).withClaim("username", username).withClaim("role", role).withExpiresAt(new Date(System.currentTimeMillis() + this.expiration)).sign(Algorithm.HMAC256(this.secret));
    }

    public String generateToken(Long userId, String username, String role, String studentId) {
        return JWT.create().withClaim("userId", userId).withClaim("username", username).withClaim("role", role).withClaim("studentId", studentId).withExpiresAt(new Date(System.currentTimeMillis() + this.expiration)).sign(Algorithm.HMAC256(this.secret));
    }

    public DecodedJWT verifyToken(String token) {
        return JWT.require(Algorithm.HMAC256(this.secret)).build().verify(token);
    }
}
```

##### 3.2.2 设备报修页面
- 实现学生报修信息加载、提交报修、表单校验、住宿信息自动填充等功能，未入住则禁止报修：
```vue
<script setup>
import { ref, reactive, onMounted } from "vue";
import { ElMessage } from "element-plus";
import { repairApi, studentApi } from "../../api";
import { formatDateTime } from "../../utils/dateFormat";
import { useUserStore } from "../../store/user";

const userStore = useUserStore();
userStore.loadUserFromToken();

const tableData = ref([]);
const dialogVisible = ref(false);
const studentInfo = ref({
  studentId: userStore.studentId || "",
  buildingNo: "",
  roomNo: "",
});

const form = reactive({
  studentId: userStore.studentId || "",
  repairType: "",
  buildingNo: "",
  roomNo: "",
  description: "",
});

// 加载学生信息（包含住宿信息）
const loadStudentInfo = async () => {
  if (!userStore.studentId) {
    ElMessage.error("无法获取学生信息，请重新登录");
    return;
  }
  
  try {
    const res = await studentApi.search(userStore.studentId);
    if (res.data && res.data.length > 0) {
      const student = res.data[0];
      studentInfo.value = {
        studentId: student.studentId,
        buildingNo: student.buildingNo || "",
        roomNo: student.roomNo || "",
      };
    }
  } catch (error) {
    console.error("加载学生信息失败:", error);
  }
};

// 加载报修记录
const loadData = async () => {
  if (!userStore.studentId) {
    return;
  }
  
  try {
    const res = await repairApi.listByStudent(userStore.studentId);
    tableData.value = res.data || [];
  } catch (error) {
    console.error("加载报修记录失败:", error);
  }
};

// 打开报修对话框
const openDialog = () => {
  if (!studentInfo.value.buildingNo) {
    ElMessage.warning("您还未入住宿舍，无法提交报修");
    return;
  }

  // 重置表单并填充宿舍信息
  form.repairType = "";
  form.description = "";
  form.buildingNo = studentInfo.value.buildingNo;
  form.roomNo = studentInfo.value.roomNo;
  form.studentId = studentInfo.value.studentId;

  dialogVisible.value = true;
};

// 提交报修
const handleSubmit = async () => {
  if (!form.repairType) {
    ElMessage.warning("请选择报修类型");
    return;
  }

  if (!form.description || form.description.trim() === "") {
    ElMessage.warning("请填写问题描述");
    return;
  }

  try {
    await repairApi.submit({
      studentId: form.studentId,
      repairType: form.repairType,
      buildingNo: form.buildingNo,
      roomNo: form.roomNo,
      description: form.description,
    });

    ElMessage.success("提交成功，请等待管理员处理");
    dialogVisible.value = false;

    // 重新加载报修记录
    loadData();
  } catch (error) {
    console.error("提交报修失败:", error);
  }
};

onMounted(() => {
  loadStudentInfo();
  loadData();
});
</script>
```

```
import axios from 'axios'
import { ElMessage } from 'element-plus'

const request = axios.create({
  baseURL: '/api',
  timeout: 10000
})

request.interceptors.request.use(
  config => {
    const token = localStorage.getItem('token')
    if (token) {
      config.headers.Authorization = `Bearer ${token}`
    }
    return config
  },
  error => {
    return Promise.reject(error)
  }
)

request.interceptors.response.use(
  response => {
    const res = response.data
    if (res.code !== 200) {
      ElMessage.error(res.message || '请求失败')
      return Promise.reject(new Error(res.message || '请求失败'))
    }
    return res
  },
  error => {
    ElMessage.error(error.message || '网络错误')
    return Promise.reject(error)
  }
)

export default request
```

## 六、用户手册（结项版 · 直接复制进你的软件说明书）
### 6.1 安装部署说明
#### 6.1.1 运行环境要求
- 操作系统：Windows 10/11 或 Linux
- JDK 版本：Java 17 及以上
- Node.js 版本：16.x 及以上
- 数据库：MySQL 8.0
- 浏览器：Chrome、Edge、Firefox 最新版

#### 6.1.2 数据库部署
1. 新建数据库 `dormitory_db`
2. 导入项目提供的 `dormitory_db.sql` 初始化脚本
3. 配置数据库账号、密码、地址与项目一致

#### 6.1.3 后端部署
1. 打开后端项目，修改 `application.yml` 数据库配置
2. 使用 Maven 打包：`mvn clean package -DskipTests`
3. 运行 jar 包：`java -jar dormitory-management.jar`
4. 后端默认启动端口：**8080**

#### 6.1.4 前端部署

1. 进入前端目录，安装依赖：`npm install`
2. 开发环境启动：`npm run dev`
3. 生产打包：`npm run build`
4. 前端默认访问地址：`http://localhost:5173`

#### 6.1.5 访问方式

1. 浏览器打开前端地址
2. 进入登录页面，选择对应角色登录
3. 系统支持**宿管员、学生**两种种身份

## 七、项目总结  【中期可先写阶段总结；结项补全】

### 1. 成果总结
本项目为**学生宿舍信息管理系统**，采用 Vue 3 + Spring Boot 前后端分离架构，实现了**宿管员、学生**两类角色的完整权限与业务流程。系统覆盖学生信息管理、宿舍管理、入住办理、设备报修、访客登记、签到等核心功。

项目已完成全部核心模块开发、接口联调、数据库设计与系统测试，可正常部署运行，达到课程设计预期目标。

### 2. 不足与改进方向
1. **缺少实时消息提醒**
   目前报修处理、离归审批、访客结果无主动推送，后续可接入 WebSocket 实现消息通知。

2. **缺少数据导出功能**
   学生、报修、访客等列表暂不支持 Excel 导出，后期可增加导出工具满足统计归档需求。

3. **移动端适配较弱**
   系统以 PC 管理为主，手机端体验一般，未来可优化响应式布局或开发小程序。

4. **缺少日志与数据备份**
   未实现操作日志记录与数据库自动备份，后续可加入以提升系统安全性。

5. **搜索与筛选可增强**
   部分列表仅支持简单查询，可增加多条件组合筛选、日期范围筛选等高级功能。
